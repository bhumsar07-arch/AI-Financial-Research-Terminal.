# RAG Architecture — AI Financial Research Terminal

## 1. High-Level RAG Conceptual Flow

```text
User Natural Language Question
           │
           ▼
[Express Gateway Authentication & Validation]
           │
           ▼ (HTTP POST /query)
[Python FastAPI RAG Service]
           │
           ├── 1. Query Analysis & Filter Extraction (Company, Fiscal Year, Doc Type)
           ├── 2. Query Embedding Generation (e.g. text-embedding-3-small)
           │
           ▼
[PostgreSQL + pgvector Hybrid Retrieval]
  - Vector Cosine Similarity Search (1 - (embedding <=> query_vec))
  - Hard Metadata Filters (company_id, doc_type, fiscal_year)
  - Limit top K candidates (e.g. K = 15)
           │
           ▼
[Reranking Layer (Cross-Encoder / Semantic Score)]
  - Reranks top 15 chunks down to top 5 highest-relevance passages
           │
           ▼
[Deterministic Financials Injection]
  - Fetches verified structured financial summary for the company & period
           │
           ▼
[Context Assembly & Grounding Prompt]
  - Injects Structured Numbers (Constants)
  - Injects Document Chunks with Citation Markers
  - Injects Speaker Roles (CEO/CFO remarks vs Analyst queries)
           │
           ▼
[LLM Generation (e.g. GPT-4o / Claude 3.5 Sonnet / Gemini 1.5 Pro)]
  - Generates Attributed Explanation ("Management stated...")
  - Distinguishes Analyst questions from Company guidance
  - Emits Structured Citations (Doc, Year, Quarter, Page, Speaker)
           │
           ▼
[Response JSON with Grounded Answer + Structured Citations]
```

## 2. Distinction Between Information Types

The architecture enforces strict rules depending on the source type:

| Source Type | Treatment in RAG Pipeline | Attribution Rule |
| :--- | :--- | :--- |
| **Structured Financial Data** (PostgreSQL) | Primary truth for all figures. Passed to prompt context as absolute constants. | *"As reported in the financial statements..."* |
| **Annual Reports / 10-Ks** (PDF Chunks) | Authoritative corporate disclosures, statutory risk factors, segment disclosures. | *"According to the FY2024 Annual Report (Page 112)..."* |
| **Management Commentary** (Transcripts) | Executive perspectives, operational rationales, strategic forward-looking statements. | *"During the Q4 FY24 earnings call, CFO [Name] stated that..."* |
| **Analyst Questions** (Transcripts) | External market skepticism, queries on margins, competitor pressures. | *"An analyst from [Brokerage] questioned whether demand was softening..."* |
